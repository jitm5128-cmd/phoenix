# 🦅 Phoenix – Travel & Tourism Website

Phoenix is a dynamic and responsive travel and tourism web application developed using **PHP, HTML, CSS, JavaScript, and MySQL**.

The project provides users with an engaging platform to explore travel destinations, browse galleries, view travel information, and access different tourism-related resources. It also includes a backend/API structure for handling dynamic website functionality.

## 📌 About the Project

Phoenix is a web-based travel and tourism platform designed to provide visitors with an easy and visually appealing way to explore travel-related content.

The website focuses on:

- Travel destination information
- Image galleries
- Travel guides
- Contact functionality
- Responsive navigation
- Informational pages
- Dynamic PHP-based functionality

The project was developed as a practical full-stack web development project to demonstrate frontend design, PHP backend development, database integration, and deployment.
